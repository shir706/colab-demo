# Colab Demo

Beginner-friendly Google Colab notebooks for trying small Python projects.

## Creative Ideas notebook

Open [creative_ideas.ipynb](creative_ideas.ipynb) in Google Colab and run its cells from top to bottom. The notebook asks for an everyday object and uses the OpenAI Responses API with gpt-6-luna to suggest one unusual, practical use.

The notebook installs the OpenAI Python SDK in the Colab runtime. When prompted, enter an OpenAI API key; getpass hides the input. The key is used only in the runtime. Do not add it to notebook code, outputs, or this repository.
